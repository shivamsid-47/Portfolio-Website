AboutMe

Full stack Developer and Researcher

Shivam is a dedicated Full Stack Developer and Cybersecurity Researcher with a strong focus on building scalable, secure, and performance-driven applications. With hands-on expertise across frontend and backend technologies, he develops modern web platforms using component-based architectures, RESTful APIs, and efficient database designs, ensuring seamless user experience and robust system functionality. His technical proficiency extends to JavaScript frameworks, TypeScript, Node.js environments, and secure deployment practices. Alongside full stack development, Shivam actively works in the domain of cybersecurity research, particularly in Network Intrusion Detection Systems (NIDS), where he explores intelligent threat detection using hybrid deep learning models such as Autoencoders and transformer-based architectures like NetBERT. He has practical experience working with large-scale datasets such as CICIDS 2017, applying advanced preprocessing techniques including PowerTransformer and MinMaxScaler while evaluating systems using metrics like precision, recall, accuracy, false alarm rate, and true negative rate. His interdisciplinary approach combines secure coding principles, blockchain-based transparency solutions, and AI-driven security analytics to design resilient digital infrastructures. With a research-oriented mindset and strong implementation skills, Shivam continuously aims to bridge the gap between secure software engineering and intelligent cyber defense systems.
